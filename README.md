# OpenVideo iOS

تطبيق iOS تجريبي لمشاهدة مقاطع فيديو قصيرة باستخدام SwiftUI وAVKit. المحتوى الحالي تجريبي وروابط الفيديو معرفة داخل VideoItem.demo.

## بناء IPA عبر GitHub Actions

1. افتح تبويب Actions في المستودع.
2. شغّل workflow المسمى **Build unsigned iOS IPA** من Run workflow، أو ادفع أي تغيير إلى main.
3. بعد انتهاء البناء بنجاح، افتح تشغيل الـ workflow ونزّل artifact المسمى OpenVideo-unsigned-ipa.
4. الملف الناتج IPA غير موقّع. يجب إعادة توقيعه بأداة توقيع موثوقة وملف provisioning مناسب قبل تثبيته على iPhone. لا ترفع شهادة Apple أو مفاتيحها إلى المستودع.

## ملاحظات

- الحد الأدنى المستهدف iOS 16.
- هذا المشروع نموذج أولي: يعرض مقاطع تجريبية ولا يحتوي على خادم أو نظام رفع محتوى أو حسابات مستخدمين.
- استخدم فقط مقاطع تملكها أو لديك إذن باستخدامها.
